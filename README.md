# 🌿 Rooted

Rooted is a mobile plant-care companion designed to help users organize, identify, and care for their plants.

Built as a UI/UX-focused mobile application with React Native and Expo.

## Features

-  Personal plant collection
- Watering schedules and reminders
- Favorite plants
- Plant care statistics
-  Plant search
- Plant identification using photos
- Plant care information
- Persistent plant data with AsyncStorage
- Local plant-care notifications


## Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
- AsyncStorage
- Expo Notifications
- Expo Image Picker
- PlantNet API
- Perenual API


## 🎨 Design

Rooted was designed with a soft botanical visual language focused on simplicity, readability, and approachable plant care.

### Design Goals

- Make plant care feel approachable
- Keep important care information easy to scan
- Create a calm, nature-inspired interface
- Reduce friction when adding and identifying plants
- Use visual hierarchy to guide users toward daily tasks
